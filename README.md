# Getty Images Watermark Removal

参考图引导的水印去除：用一张低清无水印的参考图，把同内容高清图上的水印**算出来再减掉**，而不是模糊、覆盖或涂黑。高清细节完整保留，全过程在本机完成，不联网、不上传任何图像。

本仓库同时是一个 Agent Skill（`SKILL.md` + `scripts/` + `references/`），可被 CodeBuddy / Claude 类 agent 直接加载，也可完全脱离 agent 作为命令行工具独立使用。

> **🎯 专用于 Getty Images 图片。** 本工具针对 Getty Images（以及版式相近的 Shutterstock 等图库）的预览图水印设计：一条横贯画面的半透明灰条 + 第二层不透明白色 logo/文字，外加一个独立的角落数字 ID 徽标。算法里大量"尺寸先验"和"混合模型"都建立在这类图库水印的已知形态上。**输入必须是 Getty 系列同内容的高低两版导出**——见下方「使用教程·核心前提」。非 Getty 来源的水印若形态不符，请先跑体检脚本确认类型，勿直接套用。

---

## 1. 它解决什么问题

这是 **Getty Images 专属**场景。Getty 同一张图通常有两种导出：**低分辨率但干净**、**高分辨率但带水印**。

- **低清版**：Getty 预览缩略图（通常为 ~612px 宽），**无水印**——这是 Getty 故意提供的低清样本，用来在授权前预览画面；
- **高清版**：购买/下载的高清大图（常为 2048px 宽或更高），**带有半透明水印条 + 白色 logo + 角落 ID 徽标**。

常规去水印的做法（局部模糊、内容识别填充、AI 重绘）都以牺牲水印区的真实细节为代价。本项目的做法不同：

> 把干净低清图当成**低频真值**，对齐到高清图上；水印全部藏在「两图差异」里，把差异中的水印成分建模出来，从高清图上精确减掉／重建。

因为减掉的是一个**拟合出来的水印模型**（不透明度、蒙版色、条纹模板），而不是对像素的粗暴处置，水印区之外的内容一个字节都不会动，水印区之内的高频纹理也能按物理模型恢复。

## 2. 水印混合模型（全部算法的地基）

图库水印（Getty 预览条、Shutterstock 预览条等）本质是一层**半透明蒙版**叠加：

```
T = (1-α)·O + α·C
```

| 符号 | 含义 |
|---|---|
| `T` | 带水印的目标图（高清） |
| `O` | 原始内容（未知，即要求的解） |
| `C` | 蒙版色（水印条自身的颜色） |
| `α` | 不透明度，0 = 全透明，1 = 全遮挡 |

对 `(T − A)` 关于 `A`（对齐后的参考图）做**迭代截尾最小二乘回归**：

```
slope = −α,  intercept = αC
```

一次同时解出 α 与 C。截尾（trimming）是必须的——白字/logo 像素不属于这个混合模型，不截掉会把回归整体拉歪。实测 Getty 主带 α ≈ 0.51，角落 ID 徽标 α ≈ 0.54。

## 3. 互补分解：低频取参考图，高频按 1/(1−α) 恢复

由混合模型解出 O 的直接方式是反解 `O = (T − αC)/(1−α)`，但这要求逐像素已知 α·C，且会把噪声一并放大。实际采用的是**严格互补式**：

```
O = blur(A, σ) + (T − blur(T, σ)) · gain_map        σ = 4.0
```

- **低频来自参考图** `blur(A, σ)`：水印是叠加层，不改变底层内容的低频结构，而参考图在该频段干净；
- **高频来自目标图** `(T − blur(T, σ))`：高清细节只存在于目标图里，蒙版对高频是线性缩放，按 `1/(1−α)` 增益即可还原。

两个反直觉但至关重要的约束，都是实测踩出来的：

**① 低频绝不能取 `blur(T)` 的反解值。** `(blur(T,σ) − αC)/(1−α)` 看起来能"用高清图的低频"，但 σ=4 的高斯压不掉 Getty 那种笔画宽 20–40px 的粗体白字，白字能量会泄漏进低频，再被 `1/(1−α)` 放大 2.3 倍，结果是**清晰可读的发光鬼影**——比糊块更糟。

**② 必须用严格互补式，不能写成 `A + (T − blur(T,σ))·gain`。** 后者会让参考图在 0.05–0.15 cyc/px 频段与目标图高频重复计数，实测高频能量比冲到 2.4–2.7（理想值 2.0），画面明显过锐。

σ=4.0 是安全下限：参考图（约 612px 宽）的奈奎斯特频率约 0.15 cyc/px，σ 过小会让中频段用上参考图的软化版本，画面中部发糊。

### 逐像素自适应增益

标量增益会让画面发糊（实测 1.566 vs 理想 2.061）。实际增益图按局部高频能量自适应：

```
hfs      = sqrt(box_mean(hf², 3)),   hf = (T − blur(T, σ)).mean(2)
k        = sqrt(max(1 − (noise/hfs)², 0))
gain_map = clip(ideal · k, 1, 8),    ideal = 1/(1−α)
```

局部高频能量接近噪声底的位置，增益被压到 1.0（不去放大 JPEG 噪点）；高于噪声底的位置朝 `1/(1−α)` 恢复。代价是弱纹理处的恢复比低于理想值——这是设计取舍，不是缺陷。

### 白字 / logo：第二层不透明覆盖

白色文字和 logo 不属于半透明混合模型，是叠在上面的第二层。识别方法是**中性通道超出量**：

```
gap = (T − P).min(2),    P = (1−α)·A + αC
```

取三个通道的最小值是关键——白字偏中性（三通道同时变亮），彩色纹理不会触发。白字区走**参考图原值回填**：字下面的内容在低清参考图里根本不存在，属**按设计不可恢复**，必须单独报出 `reference_fill_fraction`，不能假装恢复。

logo 影响区的掩膜必须"低阈值 + 膨胀 + 羽化"（实测工作点 `gap>0.08` → 膨胀 8px → 羽化 14px）：字芯的 gap 在 0.30–0.80，但边缘羽化带只有 0.05–0.30，用高阈值窄掩膜只盖住字芯，羽化残余被放大后就是鬼影。

## 4. 三类水印，先判类型再动手

| 类别 | 形态 | 判定特征 | 处理 |
|---|---|---|---|
| **A 条纹** | 周期性条纹/网格/细线 | 残差傅里叶域有明确方向与周期峰 | `remove_stripe_watermark.py` |
| **B 矩形蒙版** | 半透明矩形条 + 硬边白字、角落 ID 徽标 | 残差行列投影呈矩形块状；对参考图回归 α ≥ 0.15 | `rect_overlay.py` |
| **C 低对比平铺斜纹** | 斜向淡纹，压在球衣网格、草地、人群上 | 回归 α ≈ 0.00–0.11，与「纹理上采样失配」同量级 | **不动** |

**C 类是必须主动放弃的一类。** 这类淡纹的能量与真实纹理在同一个量级，α 回归给出的 0.00–0.11 无法与细纹理上采样失配区分开。硬去的结果是水印没了、球衣也变成塑料布。判据是 α 数字不是肉眼：**α < 0.08 一律不动**。

图库水印通常是 B 分支，且版式高度稳定（两组以上素材实测完全一致）：

| 元素 | 尺寸与位置 |
|---|---|
| 主带 | 恒为 **147×820 px**，贴右边缘或右下角 |
| 角落 ID 徽标 | 恒为 **29×192 px**，x 从 0 起贴左下角 |

这两个数字可以**反查漏检**：整图扫不出矩形区时，直接按尺寸去对应位置取框。

## 5. A 分支原理：周期性条纹

链路四段：**配准 → 条纹辨识 → 去除 → 质检**。

**配准**：目标图缩到分析尺寸（≤1600px）；参考图沿 x/y 各向异性缩放 + 整数平移搜索 + 亚像素精修，用重叠区 NCC 打分。NCC 决定后续走哪条路——残差只有在两图真正对齐时才是纯粹的水印成分。NCC < 0.60 时切换自参考模式（放弃参考图，只信目标图自身的高频周期性）。

**条纹辨识**：
- **方向**：对残差做二维 FFT，按角度分箱统计峰值/中位数之比，条纹在垂直于自身的方向形成能量脊；
- **周期**：沿投影坐标 `s = x·cosθ + y·sinθ` 把残差压成一维剖面（同一 s 上取平均，随机噪声被平均掉、条纹被保留），去三阶趋势后做 FFT 找峰，再两阶段相位折叠精修到亚像素；折叠能量要**扣除噪声基线**（相位分箱数随周期线性增长，不扣会系统性偏爱大周期）；
- **铺场**：一维模板按投影坐标逐像素插值回二维——斜向条纹不需要旋转图像，天然没有旋转引入的锯齿和黑边。

**去除**：条纹强度在整幅图上不均匀，不能直接减模板。滑动窗最小二乘估空间增益 `G = Σ(R·P)/Σ(P²+ε)`（R=残差，P=模板场），按窗内模板能量做置信度加权，全局/局部增益按档位混合。再用**梯度结构张量**保护真实纹理：相干性高且主方向与条纹法线一致的位置降低去除强度——否则同方向的真实纹理会被一起减掉。

**质检**：条纹抑制比 ≥ 6 dB、高频结构相关度 ≥ 0.97、高频能量比落在 0.85–1.15，三者同时满足才判 `pass`。抑制比必须在与检测一致的投影坐标系上测量，否则横条纹和斜纹的取样方向会把条纹平均掉，指标失效。

## 6. B 分支原理：矩形蒙版

链路：**区域检测 → α/C 回归 → 互补分解重建 → 白字回填 → 局部化 → QC**。

**区域检测**：残差 `T − A` 低通后做行/列投影分组，行列都命中的交叉块才算候选；`refine_box` 用 `walk()` 沿四方向找真实阶跃边界；**α 越界（<0.05 或 >1.0）即拒绝**——越界说明这不是半透明蒙版（实测草地、精修木纹、天空会被误检），记入 `rejected_regions` 原样保留。

**两种重建策略，由数据决定**：
- `complementary-lf-hf`：正常蒙版，低频取参考图、高频按 1/(1−α) 恢复；
- `reference-fill`：整框纯参考图回填。当 `region_hf ≤ 1.35 × noise_floor`（底层内容在参考图里只剩三成）时自动切换——放大高频只会放大噪声，回填反而更干净。

**局部化（性能关键）**：重建只在「区域包围盒外扩 16px 的裁剪片」上运算。主带约 150×820 像素 vs 全图 2048×1475，实测快 13 倍，且因高斯支撑完全落在外扩范围内，区域内结果逐位相同。

**性能**：2048×1365 目标图、配准缓存命中，两轮优化后平均 **2.2s/张**（9 组整批 28.4s），逐像素输出与优化前完全一致（SHA1 相同）。

## 7. 体检与框标定：为什么不能直接跑

`rect_overlay.py` 的自动检测在真实素材上有两个已证实的失效模式：**整条主带被静默跳过**（既不在 `regions` 也不在 `rejected_regions`，报告却是 `status: ok`）、**把草地球衣误检成水印**。两者都会给出"看起来成功了"的报告。

因此 B 分支的标准流程是**先跑只读体检** `inspect_watermark.py`：

```
体检 → 按 --box 执行 → 加 --clean 复核 → 按提示收几像素 → 再复核
```

三条互补定位器：
1. **α 块扫描**（主定位器）：96px 块逐块回归 α，取 `0.15 ≤ α ≤ 1.0` 的块做连通域。低通到 r=4 再回归是判据能工作的前提——细纹理失配在高频上与参考图没有稳定线性关系，低通把失配能量压掉，只剩"稳定偏移"；实测真主带 α 0.43–0.52，纹理失配 α 0.01–0.07，**只有 α 能分开两者，R² 两者都高不能当判据**；
2. **|d| 全局相对极值**（兜底）：取相对最强块 0.35 以上的块，用相对值因为不同素材水印强度差 3 倍以上；
3. **贴边条带相对基线**（专抓角落徽标）：徽标 |d| 只有主带的 0.14 倍，任何"相对全图最强块"的阈值都必然把它整块滤掉，症状是"报告里主带在、徽标凭空不见"。必须拿徽标所在条带**自身的基线**做参照。

**框边界必须实测，不信自动框。** 自动框偏 2px 就足以让 α 偏低 0.1；水印贴图边时更糟——`walk()` 在图像边缘收不到低于门限的值，会一路填到画布边界。实测角落徽标自动框 `[994,1024,4,88]` 的真实值是 `[999,1011,4,85]`，多算的 13 行在结果图底部留下一道可见亮线。手动框后徽标区残差从 15–72/255 降到 0.3–0.5/255。

**框精度 ±6px 是常态，必须靠接缝闭环收敛。** 实测同一个框 `[712,877,…]` 顶边超额台阶 +3.00/255（可见台阶），收到 `[718,877,…]` 后 +0.00/255。差这 6px 就是"有没有一道可见台阶"的区别。

## 8. 质检口径：两个容易量错的地方

**接缝要量「超额台阶」，不是结果图自己的台阶。** 结果图框边的亮度台阶可能本来就是内容自带的。判据：

```
excess = |step_clean| − |step_target|        阈值 2/255
```

| step_target | step_clean | excess | 结论 |
|---|---|---|---|
| 9.01 | 9.01 | 0.00 | 内容台阶，不是接缝 |
| +34.6 | 0.00 | 0.00 | 去掉的是水印自己的边，**正确结果** |
| +2.19 | +6.59 | **+4.40** | **真接缝**，重建留下电平差 |
| −0.61 | −0.78 | +0.17 | 重建贴合良好 |

**漏检的硬证据是残差扫描，不是 `status: ok`。** 每批都要算整图 `|T − clean|`：若某个矩形区恒为 0，说明那里**根本没被处理**。这是自动检测静默跳过主带的唯一硬证据。

**B 分支 QC 的两个坑**：高通 sigma 必须等于重建用的 `SIG_SPLIT=4.0`（用 σ=1.2 测而按 σ=4.0 重建，实测比值从 1.65 掉到 0.28，纯伪影）；统计必须排除参考图回填区（白字像素 |高通| 可达 0.5，真实纹理只有 0.01，混在一起算会被 logo 主导，比值掉到 0.17）。

## 9. 使用教程

### 环境

Python ≥ 3.10 + Pillow + numpy，纯本地，无账号无网络：

```bash
python -m pip install pillow numpy
python scripts/check_environment.py --capability watermark-removal
```

### 核心前提：必须准备两张 Getty 同内容的图

本工具**只接受两种输入**，缺一不可，且必须是同一张图的两个官方导出：

| 输入 | 命令行参数 | 是什么 | 从哪来 |
|---|---|---|---|
| **① 低清晰度预览图（干净，无水印）** | `--reference` | Getty 提供的低清预览缩略图，约 612px 宽，**没有任何水印** | 在 Getty 网页上预览/采集到的未授权低清样本 |
| **② 高清晰度水印图（带水印）** | `--target` | 已下载的高清大图，常为 2048px 宽或更高，**带半透明水印条 + 白色 logo + 角落 ID 徽标** | 购买或下载的授权高清文件 |

> **⚠️ 两个重点，务必确认：**
> 1. **低清图必须真的无水印、且与高清图是同一内容。** 它就是用来当"低频真值"的——如果低清图本身也带水印，算法会把两图的水印一起当成内容，去不干净。
> 2. **高清图必须带水印。** 本工具做的是"从两图差异里把水印算出来减掉"；若高清图已经干净，直接拿去用，不需要也不应该跑本工具（它会在干净图上凭空制造过减）。
>
> 两图**内容必须一致**（同一构图、同一裁剪）。若只是同主题的不同图，方法不适用——请先用体检脚本核对，或换自参考模式（见 SKILL.md，风险更高）。

把两张图放到同一目录下，例如：

```
my_photo/
├── 612_preview.jpg        # ① 低清干净预览图   → --reference
└── 2048_watermarked.jpg   # ② 高清水印图       → --target
```

### 标准流程（Getty 图库水印，B 分支，最常用）

```bash
cd my_photo

# ① 只读体检：判类型、定框、输出可直接粘贴的 --box 参数
python scripts/inspect_watermark.py --reference 612_preview.jpg --target 2048_watermarked.jpg

# ② 按体检给出的 --box 执行去除（可重复传多个 --box）
python scripts/rect_overlay.py --reference 612_preview.jpg --target 2048_watermarked.jpg \
    --output result.png --report report.json --box 718,877,1500,2048

# ③ 复核：漏检扫描 + 接缝实测（确认没有"整条主带被跳过"或可见台阶）
python scripts/inspect_watermark.py --reference 612_preview.jpg --target 2048_watermarked.jpg \
    --clean result.png
```

输出：`result.png`（与高清图同尺寸的去水印结果）+ `report.json`（质检报告）。

### A 分支（周期性条纹）

适用于条纹状水印（非 Getty 图库条），同样是「低清干净图 + 高清水印图」两输入：

```bash
python scripts/remove_stripe_watermark.py --reference clean_lowres.jpg --target striped_hires.jpg
# 细节优先加 --strength conservative；残留明显加 --strength aggressive
```

### 批量

```bash
# 清单每行「低清干净图|高清水印图」，可摊掉逐张起进程的导入开销
python scripts/rect_overlay.py --batch pairs.txt --output-dir out/
```

完整参数、报告字段判读、故障排查见 [SKILL.md](SKILL.md) 与 [references/](references/)。

## 11. 能力边界

- **不处理**：马赛克、不规则涂抹、纯不透明遮挡块；α < 0.08 的低对比斜纹（C 类，动了就是抹平真实纹理）。
- **不伪造参数**：B 分支的 α 必须由参考图回归得到，没有参考图就不跑。
- **不隐瞒回填**：参考图回填区的高频不可能与原始高清一致，交付时必须说明占比（Getty 主带约 0.35，角落徽标约 0.97）。
- **不覆盖原图**：结果默认写到新文件；输出路径与目标图相同会直接拒绝执行。
- **不联网**：全部计算在本机完成。
